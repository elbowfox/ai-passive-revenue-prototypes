# AI Passive Revenue Prototypes

Collection of buildable prototypes for passive/semi-passive revenue with high AI automation potential.

## Current Prototypes

1. **ContentRepurposer** - Simple web tool that takes long-form content and generates Twitter threads, LinkedIn posts, email newsletters, and short summaries. Freemium model ready (usage limits).

## Quick Start

- Open `content-repurposer/index.html` in a browser.
- Enter your OpenAI or xAI API key (stored locally).
- Paste content and generate.

## Monetization Path

- Deploy to Vercel/Netlify (free tier).
- Add Stripe for paid credits or subscription.
- Use Grok Bots / Automations for marketing content generation and customer support.
